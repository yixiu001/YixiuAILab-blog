先把一件事说明白：提示词不是"咒语"，也不是网上流传的那些神奇前缀。它只是**你把需求交给模型时所说的话**。模型看不到你的屏幕、不知道你的背景，也不会替你猜没写出来的条件——它只能根据你给出的文字来预测下一个字。

所以，提示词工程的本质就一句话：**把模糊的想法，翻译成模型能准确执行的描述。**

{% note info 一个直观的对比 %}
模糊提问：「帮我写个介绍。」

明确提问：「你是科技博主，帮我写一段 150 字以内的频道介绍，面向想学 AI 工具的上班族，语气轻松，结尾带一句行动号召。」

两句话喂给同一个模型，输出质量通常差一个量级。差别不在于模型更聪明了，而在于第二句把角色、对象、长度、风格和目标都说清楚了。
{% endnote %}

### 一、为什么结果差别这么大

模型在做的事情是「根据已有文字，推测最可能的后续」。你给的信息越少，它可以自由发挥的空间越大——而自由发挥往往意味着偏离你的预期。

- **没给对象**：它会按最通用的受众写，于是谁看了都觉得"说得不痛不痒"。
- **没给格式**：它可能给你三段散文，而你其实想要一张能直接用的清单。
- **没给标准**：它不知道你要"简洁"还是"完整"，只能折中出一个平庸版本。

### 二、三个最常见的误区

{% tabs %}
{% tab 误区一：堆砌形容词 %}
「写一个超级厉害、非常惊艳、绝对专业的方案」——这类词对模型几乎没有信息量。换成可判断的标准更有效，比如「给出 3 个可执行的步骤，每步控制在 20 字以内」。
{% endtab %}
{% tab 误区二：一次问太多 %}
把调研、写作、排版、翻译全塞进一条提示词，结果往往是每项都做得浅。更好的做法是拆成几轮，上一轮的产出作为下一轮的输入。
{% endtab %}
{% tab 误区三：不追问、直接重写 %}
第一次结果不满意，很多人删掉重问。其实明确指出哪里不对、要改成什么样，通常比从头再来更快。
{% endtab %}
{% endtabs %}
