欢迎来到这门课。开始前，我们先把整门课要做什么、需要准备什么讲清楚。

{% note info 这门课你会学到什么 %}
从账号准备、工具配置，到搭建知识库、工作流，最后完成部署发布。12 节课串成一条完整实战路径，每节都有视频和这份图文讲义。
{% endnote %}

### 一、课程结构

- **第一章 入门准备**（1-4 节）：账号、API、客户端配置，搭好第一个助手
- **第二章 实战进阶**（5-8 节）：知识库、自动化、搜索、多模态
- **第三章 部署发布**（9-12 节）：打包上线、性能与成本优化、结业项目

### 二、需要准备的环境

{% tabs %}
{% tab Windows %}
建议 Windows 10 及以上，内存 8G 以上。浏览器用 Chrome 或 Edge，便于安装各类插件。
{% endtab %}
{% tab macOS %}
macOS 11 及以上即可。首次运行第三方工具需要在「安全性与隐私」里放行。
{% endtab %}
{% endtabs %}

### 三、账号清单

后续会用到大模型平台账号、相关海外工具账号。没有的不用着急，后面每一节都会讲到怎么申请。

{% endfolding %}
