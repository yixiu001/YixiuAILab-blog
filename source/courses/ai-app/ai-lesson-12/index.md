恭喜走到最后一节。这一节我们把所有能力拼起来，完成一个真正属于你的 AI 助手。

{% note success 结业项目目标 %}
一个能回答私有文档问题、能联网查最新信息、带自动化工作流、已部署上线的 AI 助手。全部用前面讲过的组件搭成。
{% endnote %}

### 一、项目结构

{% tabs %}
{% tab 前端 %}
一个简洁的对话界面，支持文字和多模态输入，流式显示回答。
{% endtab %}
{% tab 后端 %}
负责编排知识库检索、搜索调用、模型请求，并管理密钥和限流。
{% endtab %}
{% tab 数据层 %}
向量库存知识文档，缓存层存高频结果，日志库记录调用。
{% endtab %}
{% endtabs %}

### 二、整合步骤

1. 接入知识库，导入你的专属文档
2. 接上联网搜索，补上实时信息能力
3. 配置自动化工作流，定时更新内容
4. 套用性能优化和成本安全措施
5. 部署上线，绑定域名
