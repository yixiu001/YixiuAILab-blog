这一节我们做一个具体任务：**策划一场面向新手的 AI 工具线上分享，产出一份可以直接发给合作方的方案。**

### 一、第一步：写清四要素

```
你是一位做科技内容策划的运营，偏好可执行、不空泛的方案。

请为我策划一场线上分享活动，主题是「AI 工具入门」。

要求：
- 面向从未用过 AI 工具的上班族
- 时长 60 分钟，线上进行
- 不要安排需要写代码或付费工具的环节
- 必须包含时间流程、每个环节的目标、所需物料

请用表格输出流程，表格后附一段 150 字以内的 recruitment 文案。
```

先别急着要"完美版本"。这一轮的目标是拿到一个**结构完整的初稿**。

### 二、第二步：定向追问，而不是重写

初稿常见问题和对应的追问方式：

{% tabs %}
{% tab 环节太笼统 %}
「把第 3 个环节拆成三个具体动作，每个动作写明由谁做什么。」
{% endtab %}
{% tab 语气太官方 %}
「把招募文案改成像朋友推荐的一句话，去掉『赋能』『抓手』这类词。」
{% endtab %}
{% tab 缺少落地细节 %}
「在物料清单里补上每项物料的准备时间，按耗时从长到短排序。」
{% endtab %}
{% endtabs %}

注意每一次追问都只改**一件事**。一次改三处，模型容易顾此失彼；一次改一处，你能清楚知道哪句话起了作用。

### 三、第三步：让它自检

初稿改完后，加一轮：

> 请站在审核方的角度检查上面这份方案，列出 3 个最可能被问到的问题，并给出补充建议。

这一步经常能发现你没想到的漏洞，比如"目标受众是新手，但流程里默认大家装好了软件"。

### 四、把提示词存成自己的模板

满意的提示词别用完就丢。把它存进笔记工具，把每次会变的部分留成占位符：

- **固定部分**：角色、要求、输出格式、追问清单。
- **每次替换**：主题、受众、时长、禁忌项。

用多了你会发现，真正拉开差距的不是记住了多少"神级提示词"，而是**你有没有一套稳定、可复用的提问流程**。

{% note info 这一门课到这里 %}
三节讲完：理解原理 → 套用四要素模板 → 用追问迭代出可用结果。你可以把这套方法用在写文案、做方案、整理资料等几乎任何需要"让 AI 帮你产出"的场景里。
{% endnote %}

{% folding 想把这套方法用到更长的文档？ %}
长文档建议拆成"先出大纲 → 确认大纲 → 分段写作 → 统一校对"四轮。每一轮都把上一轮的产出贴回去作为上下文，比一次性要求它写 5000 字稳定得多。
